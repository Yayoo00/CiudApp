# CiudApp 🚀

Aplicación web desarrollada en ASP.NET Core MVC (.NET 8)

## Funcionalidades
- Registro e inicio de sesión (Identity)
- Catálogo de módulos
- Página de contacto
- Diseño responsive
- Deploy en Render

## Tecnologías
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- Bootstrap
- Render (deploy)
